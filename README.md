# Hi, I'm Stefan 👋

I'm a developer from Norway with a strong interest in low-level programming, embedded systems, and backend development.

I enjoy working close to the hardware, understanding how things work under the hood, and building software that is efficient, practical, and well-structured.

## About me

- 🎓 Master's student in computer science
- ⚙️ Passionate about low-level development
- 💻 I especially enjoy working with C, C++, Arduino, and microcontrollers
- 🔧 Interested in systems programming, backend development, and performance
- 🚫 Not a frontend enthusiast, to put it mildly

## What I enjoy working on

- Low-level programming
- Embedded systems and microcontrollers
- C and C++ projects
- Arduino and hardware-near development
- Backend systems
- Performance and efficient code
- Infrastructure, Docker, and practical tooling
